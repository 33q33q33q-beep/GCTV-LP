# CycleNet 通帳管理（10_CycleNet通帳管理）

## レイアウト

| 行 | 内容 |
|----|------|
| 1 | C1/D1 … 入金合計・出金合計ラベル |
| 2 | A2=絞込、**B2=対象の選び方**（年のみ／月のみ／年と月）、E2=年、F2=月、**C2/D2=合計** |
| 3 | E3/F3 … 年・月ラベル |
| 4 | **見出し（クリックでソート）** |
| 5〜 | 取引データ |

## 絞込（2行目）

- **B2** … `年のみ` / `月のみ` / `年と月` を選択
- **E2** … 年（例: `2026年`）— 年のみ・年と月で使用
- **F2** … 月（例: `5月`）— 月のみ・年と月で使用
- 条件に合う行だけ表示（それ以外は非表示）
- **C2** … 表示中の入金合計（SUBTOTAL）
- **D2** … 表示中の出金合計（SUBTOTAL）

## ソート（4行目の見出しをクリック）

| 列 | 操作 |
|----|------|
| A4 | 日付でソート（昇順⇔降順） |
| B4 | 取引先をあいうえお順 |
| C4 / D4 | 金額の昇順⇔降順 |
| F4 / G4 / H4 | 区分・銀行名・部署区分でソート |

## セットアップ

1. スプレッドシート → **拡張機能** → **Apps Script**
2. `Setup10CycleNetPassbook.gs` を貼り付け
3. **`setupPassbookTemplate`** を実行
4. **`installPassbookTriggers`** を実行（編集・ソート用）
5. シートを再読み込み

再設定: メニュー **通帳管理** → **テンプレートを再適用**
