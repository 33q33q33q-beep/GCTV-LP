# サクラサーバー（さくらのレンタルサーバ）への設置手順

このプロジェクトは **Vite + React のSPA** です。ビルド済みの静的ファイルをサクラサーバーにアップロードして動かします。
`/admin/login` などの管理画面（CMS）は **同じ静的サイト内のルート**として配信されます。

## 1) 事前に準備するもの

- Node.js（ローカルPCでビルドするため）
- Supabase を使う場合：
  - `VITE_SUPABASE_URL`
  - `VITE_SUPABASE_ANON_KEY`

## 2) ビルド（ローカルPC）

プロジェクト直下で実行します。

```bash
npm install
```

`.env`（または `.env.production`）に本番用の値を入れてから、ビルドします。

```bash
npm run build
```

ビルド成果物は `out/` に出ます。

## 3) サクラサーバーへアップロード

FTP/ファイルマネージャで **`out/` の中身をそのまま** サイト公開ディレクトリへアップロードします。

例：サクラの「初期ドメイン」の公開フォルダに置く場合

- `www/` または `public_html/`（契約/設定により名称が異なる）配下に `out/` の中身を配置

## 4) ルーティング（重要）

このプロジェクトは React Router を使うため、`/admin/login` や `/articles/...` を直接開いても 404 にならないよう
**Apache のリライト**が必要です。

本リポジトリには `public/.htaccess` を同梱してあります。
ビルドすると `out/.htaccess` にコピーされるので、アップロードした公開フォルダ直下に `.htaccess` が存在していることを確認してください。

## 5) 動作確認

- `/` が表示される
- `/admin/login` が表示される
- `/llms.txt` が表示される
